本模块是纯数据契约层，不包含业务代码：
- `detection_result.schema.json` 定义 `DetectionJobResult`（对应 `GET /api/v1/jobs/{id}`），通过 `$defs` 内联 `bbox_image`、`detection` 子结构，并使用 `oneOf` 引用同目录的 `error.schema.json` 实现跨文件复用。
- `error.schema.json` 定义统一的 `ErrorBody`，将 `code` 枚举为建议的错误码集合（如 `INVALID_IMAGE`、`MODEL_UNAVAILABLE`、`INTERNAL` 等）。
- `samples/` 下每个 schema 配套一个 `*.valid.json` 与 `*.invalid.json`，作为 jsonschema 校验的双向用例；`README.md` 明确该目录是 G1 契约稳定的单一来源，坐标约定（`bbox_image=[x1,y1,x2,y2]` 归一化 0-1、左上原点）在 schema 描述与 README 中双重声明。
