- Schema 使用 `additionalProperties: false` 配合显式 `required` 字段列表，禁止未声明属性泄露。
- 跨文件共享结构通过 `https://astradesk.local/contracts/<name>.schema.json` 形式的 `$id` + `$ref` 引用，而非相对路径。
- 每个 schema 在 `samples/` 目录下配对提供 `*.valid.json` 与 `*.invalid.json` 两个样例，用于双向校验。
- 数值型坐标与置信度采用 `[number, minimum=0, maximum=1]` 的归一化范围约束，并在 description 中注明坐标系方向。
