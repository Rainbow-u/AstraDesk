根目录作为 Python 可安装包（`astradesk`），由 `pyproject.toml` 的 `[tool.setuptools.packages]` 将 `services/`、`packages/`、`contracts/`、`tests/`、`artifacts/`、`docs/` 等子模块纳入同一命名空间；`services.api` 暴露 FastAPI 应用入口，`services.worker` 独立轮询执行检测任务，二者共享 `packages.vision/layout/generation` 提供的算法适配层，并通过 `contracts/` 中的 JSON Schema draft-2020-12 定义 G1 API 契约，`tests/` 基于 `jsonschema` 校验合法/非法样例。运行模式由 `ASTRADESK_RUN_MODE` 环境变量在 services 与 packages 之间切换 mock/real 行为，依赖锁位于 `locks/python.lock.txt`，前端 `apps/web/` 通过 `/api` 代理调用本地 8000 端口。
