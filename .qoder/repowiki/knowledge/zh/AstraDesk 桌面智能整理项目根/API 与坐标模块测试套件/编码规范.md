- 共享夹具集中在 `conftest.py`，通过 `@pytest.fixture` 暴露给各测试文件，避免在每个文件中重复构造 `Settings` 与 `TestClient`。
- JSON Schema 校验统一通过 `jsonschema.Draft202012Validator` 配合 `referencing.Registry().with_resources(...)` 注册 `$id` 资源，再调用 `.validate()` 或 `.iter_errors()`。
- 端到端用例以 `_upload`/`_wait_job` 等模块内私有函数封装常见请求序列，保持测试主体仅表达业务断言。
- 数值断言统一使用 `pytest.approx` 处理浮点比较，避免精度误差导致的 flaky 测试。
- 错误路径断言同时检查 HTTP 状态码与响应体中的 `code` 字段（如 `INVALID_IMAGE`、`MODEL_UNAVAILABLE`），并与 `request_id` 存在性一起验证。
