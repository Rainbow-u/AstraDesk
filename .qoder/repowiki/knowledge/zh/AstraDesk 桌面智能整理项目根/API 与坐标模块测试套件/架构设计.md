测试按职责拆分为三个文件：`conftest.py` 提供共享夹具（`client`/`real_client` 通过 `create_app` + `TestClient` 启动 mock/real 模式应用，`sample_png` 生成 PNG 字节），并注入临时 `tmp_path` 作为隔离的数据目录与 SQLite DB；`test_contracts.py` 使用 `jsonschema.Draft202012Validator` + `referencing.Registry` 加载根级 `contracts/*.schema.json` 及其 samples，验证合法样例通过、非法样例被拒；`test_detection_flow.py` 端到端走 `/api/v1/projects` → `/images` → `/jobs/detect` → `/jobs/{id}` 流程，复用同一 schema 注册表校验响应体；`test_coordinates.py` 直接对 `packages.layout.coordinates` 中的 `image_to_desk`/`desk_to_image`/`clamp01` 做往返与边界断言。依赖方向单向指向被测代码（`services.api.app`、`services.api.config.Settings`、`packages.layout.coordinates`），测试之间无相互导入。
