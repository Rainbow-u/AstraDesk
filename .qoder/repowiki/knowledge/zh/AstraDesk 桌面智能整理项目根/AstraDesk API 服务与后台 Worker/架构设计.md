模块按进程边界划分为两个子包：
- `services/api`：FastAPI 应用装配层。`app.py` 通过 `create_app()` 组装 engine/session、CORS、错误处理器与路由；`routes.py` 仅做协议解析（前缀 `/api/v1`），业务逻辑委托给 `service.py`；`db.py` 用 SQLAlchemy declarative 定义 Project/Asset/Job/Detection 四张表及 engine/session 工厂；`config.py` 从环境变量加载 `Settings`（real/mock 运行模式）；`storage.py` 负责图片落盘与缩略图生成；`schemas.py` 声明 Pydantic 请求/响应模型；`errors.py` 统一抛出 `ApiError`。
- `services/worker`：独立可执行进程（`python -m services.worker`），基于 `runner.run_loop` 轮询 `jobs` 表，复用 `api.service.process_detect_job` 执行业务，形成「API 入队 + worker 消费」的解耦架构。
依赖方向：worker → api.service / api.db / api.config；routes → service；service → storage / packages.vision / packages.layout；config 被两者共享。数据库默认 SQLite，engine 以 `check_same_thread=False` 创建以支持多进程。
