- 路由函数只做参数解析与 DTO 转换，业务规则调用 `service.*` 完成，保持协议层薄封装。
- 数据库会话通过 FastAPI `Depends(get_session)` 注入，并在 finally 中关闭，避免连接泄漏。
- 异常统一通过 `errors.ApiError(code, message, status_code)` 抛出，由 `register_error_handlers` 转为 HTTP 响应。
- 配置集中由 `config.load_settings()` 从环境变量装配为 frozen dataclass `Settings`，运行时只读访问。
- 任务状态机在 `service.process_detect_job` 内维护 queued→running→succeeded/failed 转换，终态不可被重复覆盖。
