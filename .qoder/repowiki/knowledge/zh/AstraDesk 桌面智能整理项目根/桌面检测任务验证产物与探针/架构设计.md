本模块是纯产物/可执行脚本目录，无 Python 包结构，按任务编号组织：
- `hf/`：HuggingFace 数据集 `hhh134/YOLO-DeskDataset` 的 `meta.json` 与 `README.md`，描述 80 类桌面物品 YOLO txt 标注集。
- `t01_detection/`：T01 独立推理产物，由 `run_t01_detection.py` 用 ultralytics YOLOv10n 在真实 val 图上跑一次 GPU 推理，输出 `result.json` 与 `*_pred.jpg`。
- `t02_detect/`：T02 端到端 API 产物，由 `run_t02_real_detect.py` 通过 FastAPI `TestClient` 走完整 `/api/v1/projects` → `/images` → `/jobs/detect` 路径，产出 `result.json`、`annotated.jpg`、`source.jpg` 及 SQLite 数据库 `data/t02.db`；`t02_api/data/astradesk.db` 为 API 持久化库。
- 根级探针与启动脚本：`probe_torch_cuda.py` 打印 torch/cuda/device 信息并做一次 CUDA matmul 校验；`probe_wsl.sh` 诊断 WSL 内核、Python、nvidia-smi、nvcc、磁盘；`start_api.sh` 以 `ASTRADESK_RUN_MODE=real` 后台拉起 uvicorn，随后 curl 自检 `/api/v1/health` 与 `/api/v1/capabilities`；`run_t01.sh` / `run_t02.sh` / `run_t02_api.sh` 为各任务的一键入口。
依赖方向单向向外：脚本读取上游 `weights/yolov10n.pt` 与 `data/YOLO-DeskDataset`，调用 `services.api.app.create_app` 与 `ultralytics.YOLO`，不反向被业务代码引用。
